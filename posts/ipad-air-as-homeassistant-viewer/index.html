使用iPad Air作为HomeAssistant的查看器的尝试
2026-08-06 08:00 folder 问答   label HomeAssistant   iPad   智能家居  

起因

家里还留着一台iPad Air, 系统是iOS 12.5.8。本想着作为HomeAssistant的查看器使用，结果发现iOS 12.5.8的Safari浏览器不太支持HomeAssistant的前端界面，能显示，但是异常卡顿，并且基本不能触发点击。

先说结论

一开始还是抱着希望能使用的，先在AppStore找App，结果最低要求是iOS 15.0，貌似现在大部分App都是要求iOS 15.0以上了。 浏览器Safari打开有点卡，想着还能接受，结果点上去基本没反应。 然后思路转向越狱后能不能安装独立引擎的浏览器，最后还是没有找到合适的。回头看到HA Dash这个App，要求iOS8以上，居然可以。

尝试方案

调试Safari

连接iPad Air到Mac上，使用Safari的开发者工具调试，发现有JS报错。

越狱

这边其实被google的AI误导了，说越狱后可以安装独立引擎的浏览器。

使用checkra1n，失败了，提示 Expliot failed error code -31。按AI提示勾选以下三项：

  • Allow untested iOS/iPadOS/tvOS versions（允许未测试版本）
  • Safe Mode（安全模式 - 这一步极其重要，能极大提高 A7 芯片的注入成功率）
  • Verbose Boot（详细引导 - 可以看到跑代码过程） 之后成功了。

接着安装 Cydia，对网络有点要求。

接着安装 AppSync Unified，但是源失效了，作者说服务器失联了，貌似一直没恢复。在github上有release deb文件。

为了安装deb，先安装 Filza File Manager，然后下载 arm版本的 AppSync Unified，用Filza安装，提示缺少依赖 mobilesubstrate。

去Cydia安装 Cydia Substrate，然后再安装 AppSync Unified，成功了。

尝试浏览器

然后根据AI提示，试了几个浏览器，都不太好找，就不列出来了。

添加源https://repo.invoxiplaygames.uk/，安装了 Checkmate, Store!，想尝试AppStore下载旧版App，似乎还是下载不了。

Reynard Browser 看起来是个可行的方案，但是要求iOS13+。 Blinker Fluid / CyberKit 作者说是在iOS 15.4测试过。 其实这些变数来源于欧盟地区《数字市场法案》，苹果允许在欧盟地区的 iPhone/iPad 上使用真正的第三方浏览器内核，iOS12还是太老了。

最后又尝试了Polyfills，打开https://poomsmart.github.io/ 添加源到Cydia，安装了 Polyfills，然后在Safari里打开HomeAssistant，直接在欢迎页面跳不过了。 从console日志看，polyfills注入成功了，但是似乎还报JS的语法错误。

最后

回过头来发现 HA Dash 这个App，要求iOS8以上，试了一下居然可以。也算是有收获。
