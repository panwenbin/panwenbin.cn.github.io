给乐视x620默认开启无线adb
2026-07-29 08:00 folder 记录   label Android  

起因

翻出来老旧的乐视x620手机，Android 6.0的系统，开启无线adb需要用usb发送adb tcpip 5555命令，有点啰嗦，反正就放在家里，直接开启无线adb更方便。

修改build.prop

机器是root过的，所以修改build.prop文件即可，路径在/system/build.prop。先要remount/system分区，在root终端执行：

mount -o remount,rw /system

然后在/system/build.prop文件末尾添加两行：

persist.service.adb.enable=1
persist.adb.tcp.port=5555

重启手机后，adb无线连接就可以直接使用了。

使用

adb connect 192.168.1.x:5555
adb shell
